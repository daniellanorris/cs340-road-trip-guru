# Road Trip Guru
Road Trip Guru is a database-driven web application designed to help users organize road trips, destinations, attractions, and budget information. Users can manage road trip routes, connect destinations to trips, and view stored information through a web interface.

This application is meant to serve users that manage a database, rather than users that would be using an application to save their own road trip routes, trip budgets, etc.

## Citations

AI was used generally to format SQL files for this project and was used as a research tool for React props and Express routing.

### Technical Details
The project was developed using React with Vite for the frontend, Node.js/Express for the backend, and MySQL for the database. Over the course of the project, we moved from designing the database structure and relationships to connecting the database with a working web application.

## Running locally

This application can be ran locally by running:
`cd frontend` and then `npm run development`
`cd backend` and then `npm run development`

This will start both the FE and BE servers that power this Vite application.
